# LinTrafiken — frontend

React + TypeScript + MapLibre GL JS map app. Renders two data layers over a
warm-toned OpenFreeMap basemap, both served as static [PMTiles](https://protomaps.com/docs/pmtiles)
archives (no tile server, no backend at runtime):

- **Frequency Heatmap** — H3 hex grid showing transit departures/hour, by day
  type and hour.
- **Walking Catchments** — 2/5/10/15-min walking bands around city-transit
  stops.

The PMTiles files are generated by the [`pipeline/`](../pipeline) batch jobs,
not by this app — see the root [README](../README.md) for the full picture.

## Prerequisites

- Node.js 20+
- The pipeline's output tiles (`heatmap.pmtiles`, `catchments.pmtiles`) — either
  generate them yourself by running the pipeline, or drop existing copies into
  `public/tiles/` (gitignored, not committed).

## Local dev

```sh
npm install
npm run sync-tiles   # copies *.pmtiles from ../pipeline/data/processed into public/tiles/
npm run dev
```

`sync-tiles` is only a local-dev convenience; in production the tiles are
synced straight to S3 by CI, not bundled into the app.

## Scripts

| Script               | Purpose                                                   |
| -------------------- | ---------------------------------------------------------- |
| `npm run dev`        | Start the Vite dev server                                   |
| `npm run build`      | Type-check (`tsc -b`) and build for production              |
| `npm run preview`    | Preview a production build locally                          |
| `npm run lint`       | Run Oxlint                                                   |
| `npm run sync-tiles` | Copy PMTiles from the pipeline's output dir for local dev    |

## Notes

- No API key or environment variables are needed to run the frontend — the
  basemap (OpenFreeMap) and PMTiles are both fetched anonymously over plain
  HTTP(S).
- `vite.config.ts` excludes `maplibre-gl` from dependency pre-bundling; this is
  required for its worker file to load correctly under Vite's dev server (see
  the comment in that file for details).

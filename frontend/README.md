# LinTrafiken — frontend

React + TypeScript + MapLibre GL JS map app. Renders three data layers over a
warm-toned OpenFreeMap basemap, served as static [PMTiles](https://protomaps.com/docs/pmtiles)
archives (no tile server, no backend at runtime):

- **Frequency Heatmap** — H3 hex grid showing transit departures/hour, by day
  type and hour.
- **Walking Catchments** — 2/5/10/15-min walking bands around city-transit
  stops.
- **Airport** — 10-min travel-time bands to or from Linköping City Airport (LPI) by
  bus and on foot, for a chosen flight and day type (weekday/Saturday/Sunday).
  The flight dropdown, the band slider range and the list of assumptions in the
  panel are all generated from `airport-meta.json`, so a new flight schedule or
  changed limits need no frontend change.

The PMTiles files are generated by the [`pipeline/`](../pipeline) batch jobs,
not by this app — see the root [README](../README.md) for the full picture.

## Prerequisites

- Node.js 20+
- The pipeline's output: `heatmap.pmtiles`, `catchments.pmtiles`, `airport.pmtiles` and
  `airport-meta.json` — either
  generate them yourself by running the pipeline, or drop existing copies into
  `public/tiles/` (gitignored, not committed). Without the airport files the Airport tab
  shows a message asking you to run the airport pipeline.

## Local dev

```sh
npm install
npm run sync-tiles   # copies the tiles and airport-meta.json from ../pipeline/data/processed into public/tiles/
npm run dev
```

`sync-tiles` is only a local-dev convenience; in production the tiles and
`airport-meta.json` are synced straight to S3 by CI, not bundled into the app.

## Scripts

| Script               | Purpose                                                   |
| -------------------- | ---------------------------------------------------------- |
| `npm run dev`        | Start the Vite dev server                                   |
| `npm run build`      | Type-check (`tsc -b`) and build for production              |
| `npm run preview`    | Preview a production build locally                          |
| `npm run lint`       | Run Oxlint                                                   |
| `npm run sync-tiles` | Copy PMTiles and airport-meta.json from the pipeline's output dir for local dev |

## Notes

- No API key or environment variables are needed to run the frontend — the
  basemap (OpenFreeMap) and PMTiles are both fetched anonymously over plain
  HTTP(S).
- `vite.config.ts` excludes `maplibre-gl` from dependency pre-bundling; this is
  required for its worker file to load correctly under Vite's dev server (see
  the comment in that file for details).
